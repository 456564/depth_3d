# 抖音纯视频与 iw3 媒体桥

版本 1.1.0。本地扩展，与抖音、Microsoft 无关联。

## 使用

1. 在 Edge 扩展管理开启开发人员模式，加载本目录。已经加载本项目扩展时，更新文件后点击“重新加载”。
2. 刷新抖音页面，播放普通视频。不要求网页全屏或 F11。
3. 重启整个 iw3，显示模式选 Quest / Pop3D，“画面来源”选 `browser_video`，点击开始。模型和串流参数沿用自己的设置。
4. 头显“屏幕与状态”应显示网页压缩视频、源尺寸，以及成功出帧后的“NVDEC 已硬解”。仍选 wc_cuda/wc_mp/mss 时继续是截图输入。

## 数据和控制

MAIN 脚本在网页脚本前观察 MediaSource、blob 与 SourceBuffer。成功 appendBuffer 的压缩数据按原顺序复制，隔离脚本通过扩展后台送至固定 loopback 接口。后台仅接收抖音顶层页面，不接受页面提供的任意网络地址；令牌留在扩展后台。媒体有界驻内存，不写视频文件，不读取 Cookie 或浏览器凭据。

Python 按网页 currentTime、暂停和倍速选择真实媒体帧；NVDEC 必须输出 CUDA 帧，否则明确等待/报错，不自动回退截图或软解。原视频按比例进入 AI，网页控件、网页黑底和网页虚化层不会被当作视频输入。原片编码内部的黑边仍属于视频内容。

开启手柄控制后，A/扳机点击为视频播放/暂停，摇杆上下为上一条/下一条；不发送 Windows 坐标。B/Y 设置和握柄调屏沿用现有功能。退出全屏按网页实际模式选择控制。普通截图模式仍沿用原 Windows 控制逻辑。

## 边界和验证

当前支持可观察的 MediaSource 压缩输入。直播、图集、加密媒体、Worker 内独立 MediaSource、时变 timestampOffset 等未支持的输入会等待，不以录屏替代。单视频/总缓存最多 256 MiB，保留至多三个代次；超过边界需切换视频。逐作品最高画质探测后续再做。

声音仍用既有网页/进程回环采集；画面跟随网页时钟，未实现严格接收端音画时间戳同步。源失效或转码未跟上时不保证音画一致。

Node 回归：`node --test iw3/tests/browser_video_extension/*.cjs`。生产入口已有 MP4 字节经 NVDEC、真实 AI、NVENC/TCP、本机 HEVC 解码验证；这不等于当前网页或真实 Quest 已验收。浏览器重载、真实取源及无线显示仍需实际检查。

原 CSS 净屏逻辑保留。只有网页/原生全屏时隐藏已核实的控件与竖屏虚化层；普通网页恢复界面。网站 DOM 更新可能使净屏或切条选择器失效。

## 回退

iw3 主动改选原捕获方式可恢复截图模式。禁用扩展并刷新抖音可恢复网页原有行为；不需改 APK。
